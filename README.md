# LearnHub Web

Frontend for LearnHub Cameroon — a subscription learning platform with a YouTube-style community layer (previews, likes, comments, follows) where local tutors earn through Mobile Money subscriptions.

> Full project roadmap: see the LearnHub Internship Guide document. The API lives in the learnhub-api repo.

## Tech stack
- React (Vite) + Tailwind CSS
- Consumes the learnhub-api REST API (JWT auth)
- Hosting: Vercel

## Getting started

```bash
git clone <repo-url>
cd learnhub-web
npm install
cp .env.example .env   # then fill in real values (ask a lead)
npm run dev
```
